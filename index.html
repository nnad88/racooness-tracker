or set it up from scratch

Do this once, on a laptop — it is easier here. Takes about three minutes. At the end you get one link per phone, and opening that link is the whole setup on them.

1

Make a place for the coupons

Open supabase.com, sign up free, and hit New project. Any name, any region. It takes about two minutes to build.

2

Paste this once

In Supabase: SQL Editor → New query → paste → Run.

create table if not exists public.tickets (
  id         text primary key,
  pair       text not null,
  text       text not null,
  note       text,
  from_user  text not null,
  to_user    text not null,
  color      text,
  icon       text,
  serial     text,
  issued_at  timestamptz not null default now(),
  expires_at timestamptz not null,
  state      text not null default 'live',
  torn_at    timestamptz
);

alter table public.tickets enable row level security;

drop policy if exists "pair only" on public.tickets;
create policy "pair only" on public.tickets
  for all to anon
  using      (pair = current_setting('request.headers', true)::json ->> 'x-pair')
  with check (pair = current_setting('request.headers', true)::json ->> 'x-pair');
3

Bring back two things

Project Settings → Data API for the first one, then Project Settings → API Keys for the second. They are two separate pages.

Never the secret key. That one ignores all the security and would be sitting in the links you send.
